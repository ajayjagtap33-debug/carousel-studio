Comment "SKILL" to get Nvidia SkillSpector to protect your Claude Code from getting hacked. 

If you use Claude Code with multiple skills and plugins installed, your PC might already be at risk.

A recent study found that 26% of AI skills contain security vulnerabilities.

And 5% actually have malicious stuff inside them.

So to fix this, NVIDIA built a free AI tool called SkillSpector.

It basically acts like an antivirus sitting between your Claude Code and the agent skills you're about to install.

You just point it at any skill, repo, or zip file.

It scans for security risks like prompt injection, data leaks, and tool misuse.

Then it hands you a risk score out of 100.

So you know in seconds whether it's safe or not.

Think of it like a bouncer checking IDs before anything gets into your system.

And the best part? It's 100% free, open source, and works perfectly with Claude Code and Codex.

It even works with Gemini CLI too, if you're running that alongside your other tools.
