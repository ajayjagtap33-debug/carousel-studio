## 2. Hook frame (0–2 s)
SPLIT. "Run A Whole Agency" (black bold sans) + "Inside Claude Code" (white italic serif, blue box). The card is a dark Claude Code window filling with a scrolling marquee of rounded white "agent" chips with emoji icons, so the card is in constant motion. The caption builds "you can" → "run a *whole agency*" → "inside".
