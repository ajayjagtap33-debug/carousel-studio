# B-roll reference

Per-reel B-roll ↔ spoken-line tables are in `../07_visual_breakdowns/NN.md`, section 3. Every keyframe is in `../04_frames/NN/` and one contact sheet per reel is in `../04_frames/NN_contact_sheet.jpg`.

## Core principle

**Every clause gets a visual.** B-roll is not decorative; it's a literal illustration of the noun or verb being said at that moment:
- "160,000 stars" → a star counter
- "scrapes every lead" → a map with pins
- "usage limit runs out" → a usage meter turning red

The visual changes about every **1.5–2.5 s**, counting card swaps inside the split layout.

There is **almost no stock footage** (no generic people or cityscapes) in 49 reels. All B-roll is either **real product material** or **custom-designed motion graphics**.

## Spoken trigger → B-roll cheat-sheet

| When the script says… | Show |
|---|---|
| Hook: "You can now [outcome]" | Split: the **result** or the product logo on top, title text |
| "It's called X" | App-icon tile + "It's Called" label, or a white card with the name in big sans |
| "free and open source" / "N stars on GitHub" | GitHub repo page → star counter tile (rolling digits) |
| "Just install it in Claude Code" | Terminal card with the install command |
| "You just give it [input]" | Input artefact: a URL bar, an uploaded image, a prompt being typed |
| "and it'll [action]" | UI doing the action, with a highlight box and cursor; or a mascot animation |
| "Then it'll [action 2]" | Next screen, or a diagram node lighting up |
| Any number | Counter tile / big serif number on dark |
| A competitor / paid tool | Competitor logo + red strike or red price |
| "works with Claude Code, Codex…" | Row of logos |
| "Plus…" | New card (often a light-leak flash or a slide transition) |
| List item "The second is X" | Section card "Plugin Number Two" (blue italic box) → product card with an "2/5" badge |
| CTA | Full talking head, "comment 'WORD'" glow |

## Sourcing recipe (for your own reels)

1. Screenshot the GitHub repo, README, star history (star-history.com) and the product site. Capture at 2× scale for crispness.
2. Screen-record the tool running (terminal + output) at 60 fps. Crop to the area that matters.
3. Build 3–6 simple motion graphics per reel: a counter tile, a logo tile, a flow diagram, a stat chart, and a mock UI if needed. Make them reusable templates; the original reuses its graphics across reels (19/27, 26/30, 41/45).
4. Place every card on the off-white palm-shadow canvas (light) or over a blurred copy of itself (dark).
5. Add a highlight box on the exact word or button for each feature claim.
