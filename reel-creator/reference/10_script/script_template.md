# Script template (fill-in), Nick Saraev format

Target: **120–160 words, ~35 s at ~245 wpm**. Listicle: 160–230 words, 45–55 s. One sentence per caption line.

## A. Single tool

```
[HOOK, 0-4s]       You can now [dramatic outcome] with Claude Code, completely free.
                   (alt: "[Brand] just open-sourced…" / "This free AI tool lets you…" / "Someone just…")

[NAME + PROOF]     It's called [NAME], and it's a free, open-source [category] that's already crossed [N] stars on GitHub.
                   (alt proof: "built by a former director at Google", "used by [big co] internally", "found 7,000 issues in their own codebase")

[MECHANISM 1]      You just [give it / point it at / tell it] [simple input],
[MECHANISM 2]      and it'll [visible action 1 with concrete nouns].
[MECHANISM 3]      Then it'll [action 2], and even [surprising action 3].

[PLUS]             Plus, it [comes with an MCP / works with Claude Code and Codex / costs nothing / works on 170+ models],
                   so [practical benefit].

[CTA, last 3-4s]   So if you want to try this for yourselves, just comment [WORD] down below and I'll send you the link directly.
```

## B. Listicle (3–5 items)

```
[HOOK]     Don't use Claude Code until you've installed these [N] free plugins.
[ITEM 1]   The first is [Name], which [one-line benefit with a number].
           [One proof/detail sentence.]
[ITEM 2]   The second is [Name]. [Benefit.] So [practical result].
[ITEM 3]   The third is [Name], which [benefit].
[ITEM N]   And finally, there's [Name], which [benefit].
[CTA]      So if you want them all for yourselves, just comment [WORD] down below and I'll send you the links directly.
```

## Writing rules

1. First word at 0.0 s. No "hey guys" and no intro.
2. Say "free" at least twice (hook + somewhere else) when it's true.
3. Use at least one big concrete number (stars, users, tokens, models, ms, $).
4. Name a familiar anchor: Claude Code, Codex, Google, Anthropic, or a paid incumbent you replace (Ahrefs, ElevenLabs, Veo).
5. Mechanism = 3 verbs the viewer can *see* on screen (scrape, map, rebuild, generate, scan). Each verb should have B-roll (see ../11_broll/).
6. Use "Plus," for the bonus beat and "And finally," for the last list item.
7. CTA keyword = one word, ideally the tool name or category. Repeat it as line 1 of the caption: `Comment "WORD" to get …`.
8. Keep sentences short enough to show as 1–3 caption words at a time.
