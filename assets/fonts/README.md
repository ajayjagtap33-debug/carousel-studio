# Fonts

- `TeXGyreHeros-*.otf`: TeX Gyre Heros, a free Helvetica clone (GUST Font License, free to use and redistribute,
  http://tug.org/fonts/licenses/GUST-FONT-LICENSE.txt). Used as the stand-in when Helvetica Neue isn't available,
  and for text measuring in the `tmv-study` theme.
- Helvetica Neue is licensed (Monotype), so it isn't included. Drop its .otf/.ttf files here (file names containing
  "HelveticaNeue", e.g. `HelveticaNeue-Roman.otf`, `HelveticaNeue-Bold.otf`) and the TMV exports use it automatically.
